# Anonymous review package

The release excludes author names, institutional details, local account names,
machine paths, access credentials, Git working history, operating-system process
logs, and manuscript source. Checkpoint tensors are retained exactly; path-bearing
metadata is replaced with portable locations. The private source-to-release
mapping is kept outside this repository. Git commits use the anonymous account.

CVPR 2027 requires contributed content to be self-contained in submission and
supplementary files. Do not insert a link to this repository or its model assets
into a review manuscript as a substitute for those files. The code-only archive
is suitable for inclusion in supplementary material; check the submission portal's
current size allowance before adding model archives. This repository is a user-
requested archive, not a claim that an external URL is an allowed supplement.
